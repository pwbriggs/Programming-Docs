If you are on a Mac, you can't really download the FRC Game Tools because they are Windows only. As an alternative, we can download QDriverStation (which is a replacement for the FRC Driver Station) in FRC Game Tools, and it's the Game Tool that we use the most often.

Step 1: Head to this link and download the zip file for Macs: [Link](https://github.com/FRC-Utilities/QDriverStation/releases/tag/v21.04)

Step 2: After you have downloaded the zip file, open it in Finder, this should automatically unzip the file into an application.

Step 3: Click on the application to try and open it. If it prompts a malware:
- Throw the application to inside the Application tab in Finder
- Open up Terminal, and run ```xattr -d com.apple.quarantine /Applications/QDriverStation.app```

Now, it should no longer be marked as malware and you can open QDriverStation!
