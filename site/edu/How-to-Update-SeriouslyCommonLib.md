How to update SCL:

IN GITHUB DESKTOP

1. Open GitHub Desktop
2. Click on "Current branch", then "New branch"
3. Make a branch off of main, name the branch "update-scl", then press "Create Branch"
4. Right click "Current repository", and open command prompt

IN THE COMMAND PROMPT

5. Check for git, type in "git". If a bunch of code appears, you know you have git
6. Type in "git pull", and log in from your browser. After logging in, go back to command prompt
7. Type in "cd SeriouslyCommonLib"
8. Type in "git checkout main"
9. Type in "git pull"

CHECK FOR THE UPDATE

10. Type in "cd .."
11. Type in "git status"
12. If it shows in the command prompt "modified: SeriouslyCommonLib (new commits)", then click back to GitHub Desktop

BACK TO GITHUB DESKTOP

13. On the bottom left, press "commit to update-scl"
14. Go to "Repository" on the top bar, then press "push"

GO TO THE GITHUB WEBSITE

15. Go to the "TeamXbot2026" folder on the GitHub Website
16. A green button should appear at the top about creating a new pull request. If so, press on the green button and create a pull request.
17. If the green button doesn't appear, manually make a pull request.
